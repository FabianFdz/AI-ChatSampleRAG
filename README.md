# AI Chat RAG

A Retrieval-Augmented Generation (RAG) chat application with LangChain and LangGraph.

## Features
- Upload up to 3 PDF/text files for knowledge base
- AI-powered chat with memory of the session
- Built with Next.js (frontend) and Node.js/TypeScript (backend)

## Stack
- **Frontend:** Next.js
- **Backend:** Node.js with TypeScript, LangChain, LangGraph
- **Storage:** In-memory (PoC)
